###  Описание проекта

To-Do List на Vue 3 и Vite. Интерфейс приложения перенесен с ванильного JS на Vue 3. Стилизация реализована с помощью классов Tailwind CSS.

### Запуск проекта

Перед началом работы убедитесь, что у вас установлен Node.js версии 18.x или выше.

1. Установите файлы проекта с репозитория.
2. Перейдите в папку проекта и в консоли выполните команды:
```bash
npm install
npm run build
```
3. После этого откройте ссылку из терминала (обычно `http://localhost:4173/`).

### Зачем в проекте нужны `watch` и `v-if`

#### 1. `watch`
* **
* В главном компоненте (`App.vue`)**: Мы настроили наблюдение за массивом задач. Как только пользователь совершает любое действие (добавляет новую задачу, удаляет старую или отмечает галочкой выполненную), `watch` это фиксирует и автоматически перезаписывает обновленные данные в `localStorage`. 
* **В модальном окне (`AddTodoModal.vue`)**: `watch` следит за флагом открытия окна. Когда окно открывается, он проверяет режим: для редактирования — подставляет текст задачи, для создания — очищает поле. Также он сразу переводит фокус (курсор) в поле ввода, чтобы пользователю не приходилось лишний раз кликать мышкой.

#### 2. `v-if`
* **В списке задач (`TodoList.vue`)**: Мы применили `v-if` для обработки пустых состояний. Если массив отфильтрованных задач содержит элементы (`v-if="tasks.length > 0"`), мы рендерим полноценный список `<ul>`. Если пользователь удалил все задачи или поисковый запрос ничего не выдал, срабатывает блок `v-else`, который убирает пустой список из структуры страницы и показывает текст-заглушку «Список задач пуст или ничего не найдено».
* **В элементе задачи (`TodoItem.vue`)**: Здесь `v-if="task.done"` используется для вывода скрытого текста `(выполнено)`. Обычный пользователь видит задачу просто зачеркнутой, но программы-экранные дикторы (скринридеры) для незрячих людей за счет этого условия зачитают статус задачи вслух.
